# Leia-me primeiro — V04.3.5

1. Extraia o pacote na raiz do projeto e confirme a substituição.
2. Execute os testes de sintaxe do backend.
3. Execute o build do painel administrativo.
4. Faça o deploy com o polling automático desativado no primeiro teste.
5. Abra Integração iFood e execute Auditoria.
6. Revise pendências críticas antes de usar os botões de correção automática.

A consulta remota depende de credenciais, Merchant ID, Catalog ID e permissões válidas no aplicativo iFood.
