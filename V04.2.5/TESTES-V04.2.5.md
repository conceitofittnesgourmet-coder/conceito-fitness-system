# Testes

1. Execute os `node --check` informados.
2. Execute `npm run build` dentro de `admin`.
3. Abra Opções por Produto.
4. Selecione um produto, habilite grupos e limite opções.
5. Defina uma opção padrão, salve e recarregue.
6. Teste a cópia de configuração para outro produto.
7. Confirme as escolhas no Cardápio Online.
