# Testes — V04.3.3

1. Execute os `node --check` indicados na entrega.
2. Execute o build do painel administrativo.
3. Faça o deploy com o polling automático inicialmente desativado.
4. Importe um pedido de homologação.
5. Confirme o pedido dentro do prazo.
6. Execute o polling e confirme o evento `CONFIRMED`.
7. Inicie o preparo e execute o polling.
8. Para retirada, use `Pronto`; para entrega própria, use `Despachar`.
9. Consulte os motivos e faça um cancelamento apenas em pedido de teste.
10. Confirme que erros e comandos ficam registrados no painel.
