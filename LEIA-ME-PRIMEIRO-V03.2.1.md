# LEIA-ME PRIMEIRO — V03.2.1

## Instalação

1. Faça backup ou confirme que o projeto está versionado no Git.
2. Extraia este ZIP na raiz do projeto.
3. Confirme a substituição dos arquivos existentes.
4. Entre na pasta `admin` e execute o build.

## Validação recomendada

```cmd
cd admin
npm run build
cd ..
git diff --check
git status
```
